# MC study

Analysis scripts for microbiome profiling in MC study.

## Structure
- Scripts/: R analysis scripts
- Metadata/: Sample metadata
- QIIME2 outputs and derived objects are generated locally and not tracked

## Reproducibility
All figures and results can be regenerated by running the scripts in order:
- MC_study_dada2-script
- MCstudy_data-processing.R
- MCstudy_stats-plots.R
